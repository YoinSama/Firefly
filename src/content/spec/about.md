# 关于我 / About Me

欢迎来到 **格里芬 S09 辖区**，指挥官。

这里是一个用来堆放日常碎碎念、ACG 杂谈和技术折腾记录的地方。没有 KPI，没有更新压力，想到什么就写什么，写不下去就先搁着。

随手逛逛就好，走之前欢迎留个脚印。

## 👋 关于我

- 一个普通的 ACG 爱好者，二次元浓度不高不低，属于「什么都看一点，什么都不算精通」的类型
- 写代码纯粹是兴趣驱动，没有「成为大佬」的宏大目标，能跑起来、能解决问题就很开心
- 严重拖延症患者，看过不少教程和课程，看完的不到三分之一

> [!TIP]
> 如果你是顺着搜索引擎点进来的，大概率是某篇折腾记录帮到了你。那这篇文章就没白写。

## 🛠️ 关于本站

这个站点的骨架是 **[Astro](https://astro.build)**，主题用的是 **[Firefly](https://github.com/CuteLeaf/Firefly)**（它又脱胎于 [Fuwari](https://github.com/saicaca/fuwari)）。我对它做了不少魔改，其中最大的一块就是下面那张游戏资料卡。

日常流程大概是这样：

1. 在 **Obsidian** 里写 Markdown，frontmatter 直接可视化编辑
2. `git push` 到 GitHub
3. **Cloudflare Pages** 自动拉取、构建、部署，全程不用我管
